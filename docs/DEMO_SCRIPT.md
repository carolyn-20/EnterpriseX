# Demo Script (8–12 minutes)
1. Start the stack; show `docker compose ps` and health endpoints.
2. Sign in with the demo admin; show dashboard cards.
3. Create a vendor; add a product; show product in table.
4. Create PO using vendor/product; explain it starts pending approval.
5. Approve PO; receive goods; show inventory increased and stock movement.
6. Create a sales order for a quantity within stock; fulfill it; show invoice and stock decrease.
7. Record a payment; show invoice status and payment record.
8. Show report endpoints and Swagger docs.
9. Run API/Python tests; explain transaction rollback and role checks.
10. Explain demo limitations honestly.
