# Submission Checklist

- [ ] Source repository pushed to GitHub
- [ ] `docker compose up --build` succeeds
- [ ] Dashboard opens at localhost:3000
- [ ] API health is OK at localhost:4000/health
- [ ] FastAPI docs load at localhost:8000/docs
- [ ] Create vendor and product
- [ ] Purchase order creation, approval and receipt demonstrated
- [ ] Inventory reflects receipt
- [ ] Sales order fulfillment and invoice creation demonstrated
- [ ] Payment workflow demonstrated
- [ ] `npm test` passes for API
- [ ] `pytest -q` passes for reports
- [ ] API docs/Postman collection included
- [ ] Screenshots/demo recording captured
- [ ] Known limitations disclosed
- [ ] No secrets or real data committed
