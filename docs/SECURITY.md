# Security notes
- Demo secret values must be replaced before any public deployment.
- Seed demo credentials are public in this repository and must not be used outside local training.
- No real customer, financial, or personally identifying data should be entered.
- Configure TLS, least-privilege database users, secure secret storage, rate limits, review of dependencies, and backups for deployment.
- The current role model is an illustrative minimum, not a complete authorization audit.
